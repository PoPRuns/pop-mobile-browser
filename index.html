02 THE IDEA

Preserve each
difference.

One phone game can have dozens of screen sizes, languages, device-specific versions, and sometimes entirely different gameplay. This atlas treats each SHA-256-identified build as its own record, while retaining your experimental gameplay groups.

Play in your browser: choose a build, open its SHA-256-specific J2ME index link, download the matching JAR yourself, and import it using the file picker. The browser verifies its SHA-256 before caching and playing it through freej2me-web. A local preview server can optionally serve a separately installed JAR collection.
